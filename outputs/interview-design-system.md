# 면접전형 디자인 시스템

현재 컬러 기준: [Hanna Yakubenko — Study Dashboard | UI/UX Design](https://www.behance.net/gallery/187415043/Study-Dashboard-UIUX-Design)

## 현재 위계 원칙

블루는 주요 작업을 확정하는 실행 버튼과 키보드 포커스에 집중합니다. 선택 중인 탭·지원자·평가 옵션과 보조 도구를 블루 실행 버튼과 구분합니다.

| 위계 | 대상 | 표현 |
|---|---|---|
| Primary | 최종 평가 저장, 평가 제출, 모달의 발송·확인·일정 추천 실행 | 블루 채움 + 흰색 텍스트 |
| Secondary | 질문 생성, 녹음, 임시저장, 메모 저장, 상세 보기, 재생성, 취소 | 흰색 + 회색 테두리 + 슬레이트 텍스트 |
| Navigation | 1차·2차 면접, 지원서·평가, 평가·히스토리·메모 | 선택 시 연한 회색 채움 + 짙은 글자·얇은 경계선 |
| Selection | 지원자 카드, 합격·불합격·보류 선택 | 낮은 채도의 면·테두리; 실행 버튼과 구별 |
| Quiet | 닫기 등 아이콘 버튼 | 투명 배경 + 회색 아이콘 |

기본 화면에서 블루 채움은 최종 평가 저장에 사용합니다. 모달이 열리면 해당 모달의 주요 작업을 블루로 표시합니다. 비활성 주요 버튼은 회색으로 낮춥니다. 평가 결정은 중립색 세그먼트 컨트롤로 선택하며, 결과 배지는 별도의 의미 색상으로 구분합니다.

## 수정 범위

레퍼런스 첫 화면의 **학생용 블루 테마**를 기준으로 팔레트만 변경했습니다. 레퍼런스의 교사용 딥 틸 테마는 적용하지 않았습니다. 로열 블루는 주요 실행에만 남기고 강조면은 저채도 슬레이트·회색으로 재구성했습니다. 밝은 회색 배경, 흰색 카드, 차콜 텍스트를 사용합니다.

수치는 정적 이미지의 화면 샘플과 시각적 비교를 바탕으로 정한 적용값입니다. 원본 CSS 또는 Figma 토큰으로 공개된 값은 아닙니다. Primary는 레퍼런스의 블루 활동 카드 화면 샘플에서 빈도가 높은 `#1B43F3`을 기준으로 삼았습니다. Hover·Active·Focus는 같은 팔레트에서 확장했습니다.

Plus Jakarta Sans와 한글 폴백, 크기·두께·행간·간격·섹션 구성은 유지하되, 가용 폭에 맞춰 3열·2열·1열로 재배치합니다. Radius는 아래 Atlassian 공식 토큰으로 교체했습니다. React 로직과 요소 순서는 유지하고 시각적 우선순위·선택 상태를 나타내는 속성만 추가했습니다. 테마는 면접전형과 그 화면의 공통 헤더·사이드 메뉴에만 적용합니다.

## 컴포넌트 적용

- 주요 실행 버튼: 로열 블루 배경 + 흰색 글자. `data-intent="primary"`.
- 보조 작업 버튼: 흰색 + 옅은 회색 테두리. `data-intent="secondary"`.
- 사이드 메뉴·탭 선택: 회색 배경 + 슬레이트 아이콘·글자.
- 선택한 지원자: 옅은 회색 배경 + 얇은 슬레이트 강조선.
- AI 도구: 중립색 면과 아이콘; 질문 생성·녹음 버튼은 보조 위계.
- 평가 선택: 하나의 연한 배경 안에서 선택 항목만 흰색 표면·짙은 글자·약한 그림자로 표시하는 세그먼트 컨트롤입니다. `aria-pressed`와 기존 단일 선택·disabled·저장 로직은 유지합니다.
- 헤더·카드: 흰색, 얇은 회색 구분선.
- 입력창 Focus: 블루 경계선과 3px 반투명 링.
- 비활성 주요 작업: 회색 배경·글자, disabled 동작 유지.

## 유지한 타이포그래피와 형태

타이포그래피와 간격은 이전 [Fintora 레퍼런스](https://www.behance.net/gallery/245057705/Modern-Fintech-CRM-SaaS-Dashboard-UX-UI-Case-Study) 기반의 구현을 유지합니다. 이번 Study Dashboard 레퍼런스에서 폰트·레이아웃을 새로 추출하거나 교체한 것이 아닙니다.

- 영문·숫자: Plus Jakarta Sans Variable, 로컬 WOFF2, 200–800.
- 한글 폴백: Pretendard Variable / Pretendard / Apple SD Gothic Neo / Malgun Gothic / sans-serif.
- 페이지 제목 26px·600·행간 1.3(모바일 24px), 선택 지원자 제목 18px·600, 프로필 이름·모달 제목 16px·600, 섹션 제목·카드 이름 14px·600, 본문·컨트롤 13px, 보조 12px, 배지 11px.
- 본문 행간 1.5, 긴 설명문 1.65, 자간 -0.015em, 큰 제목 자간 -0.04em.
- 간격: 4 / 8 / 12 / 16 / 20 / 24 / 32px.
- Radius는 아래 Atlassian 토큰을 적용합니다.
- 넓은 화면은 유동 3열, 중간 폭은 2열, 작은 폭은 1열로 재배치합니다. 섹션 순서는 지원자 목록 → 지원서 → 평가입니다.
- 상태 전환 160ms ease, 동작 줄이기 설정에서는 전환 제거.

## Radius: Atlassian / Jira 기준

출처: [Atlassian Design System — Radius](https://atlassian.design/foundations/radius/). 공식 문서에서 확인한 현재 값을 로컬 CSS 변수로 매핑합니다.

| 공식 토큰 | 적용값 | 로컬 변수 | 적용 대상 |
|---|---|---|---|
| radius.xsmall | 2px | `--int-radius-xsmall` | 작은 세부 요소용 토큰 |
| radius.small | 4px | `--int-radius-small` | 배지·태그·상태 레이블 |
| radius.medium | 6px | `--int-radius-control` | 버튼·탭·입력창·셀렉트·탐색 항목 |
| radius.large | 8px | `--int-radius-card` | 3열 패널·지원자 카드 |
| radius.xlarge | 12px | `--int-radius-modal` | 모달 |
| radius.full | 999px | `--int-radius-full` | 사용자 아바타 등 원형 요소 |

기존 24px 패널·16px 지원자 카드·12px 입력창·캡슐형 버튼을 위 값으로 줄였습니다. Focus outline의 간격은 공식 안내에 맞춰 2px로 설정했습니다. 색상 위계·섹션 구성·기능 로직은 유지합니다. 그리드 너비·바깥 여백·섹션 높이는 아래 반응형 규칙으로 조정합니다.

## 반응형 및 공간 활용

- 관리자 영역과 페이지의 중복 좌우 패딩을 제거하고 중앙 최대 너비 제한을 해제합니다.
- 바깥 여백은 일반 화면 16px, 모바일 8px입니다. 섹션 사이 간격은 12px입니다.
- 사이드 메뉴를 제외한 실제 콘텐츠 컨테이너의 폭으로 반응합니다.
- **가용 폭 1080px 초과:** 지원자 목록 260–360px, 평가 320–480px로 유동 조절하며 지원서가 남는 너비를 모두 사용합니다. 각 열의 목표 너비는 목록 23cqw / 평가 29cqw입니다.
- **가용 폭 720–1080px:** 왼쪽 지원자 목록, 오른쪽 지원서 아래 평가의 2열입니다. 목록을 스크롤 중에도 선택할 수 있도록 sticky로 유지합니다.
- **가용 폭 720px 이하:** 지원자 목록 → 지원서 → 평가를 1열로 배치하고 페이지 세로 스크롤을 사용합니다. 목록·지원서 내용은 내부 스크롤로 읽습니다.
- **브라우저 폭 600px 이하:** 탐색 메뉴를 56px로 줄이고 헤더의 이메일·설정 텍스트를 접습니다. 역할 선택과 사용자·설정 아이콘은 유지합니다.
- 검증한 브라우저 폭: 1920px(3열), 1024px(2열), 390px(1열). 가로 넘침이 없는 것을 확인했습니다.

## 구분선 사용 원칙

제목·선택 배경·카드·여백으로 이미 구분되는 영역의 가로선은 제거합니다. 면접 평가자 명단 위, 필터 아래, 지원자 헤더 아래, AI 도구 영역 아래, 지원서 프로필·섹션·제목의 중복 구분선은 제거합니다. 반면 1차·2차 면접, 지원서·평가, 평가·히스토리·메모 탭은 내용 전환 범위를 나타내므로 하단 1px 구분선만 유지합니다. 선택 탭은 옅은 배경색·글자 두께·테두리로 구분하고 별도 굵은 밑줄은 사용하지 않습니다. 패널·카드 외곽, 입력창·선택 컨트롤의 테두리와 모달의 헤더·푸터 경계는 유지합니다. 공유 컴포넌트의 변경은 면접전형 스타일 범위에서만 적용합니다.

## 정보 밀도와 가독성

- 글자 크기, 주요 버튼 색상 위계, 3·2·1열 반응형 구성은 유지합니다.
- 일반 본문 행간 1.5, 긴 설명문은 1.65입니다.
- 페이지 세로 여백 16px, 제목 아래 16px입니다.
- 데스크톱 탭 높이 32px·그룹 상하 여백 4px, 필터 높이 32px·필터 간격 6px입니다.
- 모바일 탭·필터는 36px로 유지하고 평가 버튼도 최소 높이 36px를 확보합니다.
- 지원자 요약 카드 상하 패딩은 10px, 좌우 12px, 카드 간격 6px입니다.
- 지원서 콘텐츠 패딩은 12px 16px, 섹션 하단 패딩 8px·여백 12px, 제목 아래 8px, 정보 행 아래 4px입니다.
- 프로필 사진은 기존 54×72px에서 가로·세로 2배인 108×144px로 확대했습니다. 프로필 아래 중복 여백은 줄인 상태로 유지합니다.
- 평가 콘텐츠 패딩 10px, 평가 그룹 간격 10px, 텍스트 영역 패딩 8px 10px입니다.
- 주요 저장·제출 버튼 높이와 폰트 크기는 줄이지 않습니다.

## 요약 카드: 평가자와 지원자 목록

첨부된 금융 요약 카드의 정보 위계를 참고하여 이름 → 상태 → 레이블/값 구조로 통일했습니다. 의미 없는 메뉴나 원형 차트는 추가하지 않습니다.

- **평가자 카드:** 상단 작은 레이블·14px·600 이름·우측 제출 상태, 하단 소속·평가 결정·수정 일시, 별도 코멘트 영역입니다. 현재 정보와 원래 열람 권한을 유지하며 코멘트는 생략하거나 잘라내지 않습니다.
- **지원자 카드:** 상단 작은 레이블·14px·600 이름·우측 진행 및 일정 상태, 중간 지원 직무, 하단 면접 일정·완료 평가 수입니다. 구체적인 일시가 없으면 기존 일정 상태를 표시하고, 그 상태도 없으면 미정으로 표시합니다.
- 하단 정보 사이에는 옅은 세로 구분선만 사용합니다. 이름과 주요 값은 짙고 굵게, 레이블과 직무는 중립 보조색으로 구분합니다.
- 카드 반경 8px, 기존 선택 카드의 중립 배경·좌측 강조선·Hover·클릭 동작을 유지합니다.
- 좁은 평가자 카드는 수정 일시를 다음 줄에 배치하며 긴 이름·직무·시간·코멘트가 잘리지 않게 합니다.

## 폰트 위계

카드의 이름을 19px·650에서 14px·600으로 낮춰 선택한 지원자와 섹션 제목보다 과도하게 강조되지 않도록 했습니다.

| 역할 | 크기 | 두께 | 표현 |
|---|---|---|---|
| 페이지 제목 | 26px / 모바일 24px | 600 | 페이지 전체의 최상위 제목 |
| 선택한 지원자 헤더 | 18px | 600 | 현재 보고 있는 상세 대상 |
| 프로필 이름·모달 제목 | 16px | 600 | 상세 정보 내부의 주요 대상 |
| 섹션 제목 | 14px | 600 | 지원서 항목·최종 평가·평가자 명단 |
| 지원자·평가자 카드 이름 | 14px | 600 | 목록 항목 식별 |
| 본문·코멘트·버튼·탭 | 13px | 400 / 버튼 500 | 업무 내용과 실행 |
| 레이블·직무·날짜·집계 | 12px | 400–500 | 중립색 보조 정보 |
| 상태 배지 | 11px | 500 | 작은 상태 표시 |

카드 내 날짜·소속·완료 수는 500으로 낮추고 평가 결정만 600을 사용합니다. 제목·이름은 짙은 텍스트, 본문은 보조 텍스트, 레이블은 muted 색상을 사용합니다. 블루 실행 버튼과 선택 탭의 기존 위계는 유지합니다.

## 상태 배지 및 탭 구분선

| 불합격 | `#FFECEB` | `#AE2E24` | danger |
| 미정·평가대기 | `#0515240F` | `#505258` | neutral / text.subtle |

탭 그룹 하단은 1px `#EEF0F4`로 옅게 통일합니다. 대상은 1차·2차 면접, 지원서·평가, 평가·히스토리·메모의 세 탭 그룹입니다. 패널 외곽선·카드 테두리·입력창 테두리는 변경하지 않습니다. 활성 탭의 굵은 밑줄도 다시 추가하지 않습니다.

## 세그먼트 컨트롤과 확대 프로필

- 합격·불합격·보류는 하나의 옅은 회청색 트랙 안에 같은 너비로 배치합니다. 선택 항목만 흰색 표면·약한 그림자·굵은 글자로 강조합니다.
- 선택 항목 주변 구분선은 숨기고 비선택 항목 사이에만 옅은 세로선을 표시합니다. 기존 Jira Radius 기준을 유지해 바깥 8px·내부 6px입니다.
- 모든 항목은 기존 `onChange`를 사용하고 `aria-pressed`로 선택 상태를 제공합니다. 평가 저장·권한·disabled 조건은 변경하지 않습니다.
- 증명사진은 108×144px, 오른쪽은 지원자 레이블·16px 이름·이메일·연락처·생년월일 구조입니다. 이메일은 전체 너비, 연락처와 생년월일은 하단 2열로 구분합니다.
- 좁은 프로필 컨테이너에서는 연락처·생년월일을 1열로 배치하고 이메일은 줄바꿈합니다. 사진 크기는 유지합니다.
- 새 프로필 레이아웃은 면접전형에서만 `profileLayout="summary"`로 사용하며 다른 페이지의 기본 레이아웃은 유지합니다.

## 지원서 미니멀 테이블

면접전형의 지원서 상세에만 `contentLayout="table"`을 적용합니다. 각 제목 아래는 실제 HTML `table`로 구성하고 항목명은 행 헤더(`th scope="row"`), 내용은 `td`로 표시합니다.

- 기본정보·주소·병역·보훈·장애·학력·경력·자격증·어학·사회활동·자기소개·포트폴리오·지원정보를 모두 유지합니다.
- 항목명 셀은 옅은 중립 배경과 12px·500, 내용은 흰색 배경과 12px·400입니다. 항목명과 내용의 글자 크기를 12px로 통일하며 이름 등 필요한 값만 600으로 강조합니다. 같은 미니멀 테이블 컴포넌트에 공통 적용합니다.
- 행 사이의 얇은 구분선과 표 위·아래 경계만 사용하며 굵은 테두리·과한 격자는 피합니다. 표 상단·하단·중간 행 구분선은 모두 `--int-tab-divider` (`#EEF0F4`)로 통일합니다.
- 셀 패딩은 6px 10px, 항목명 폭은 112px입니다. 모바일은 84px·6px 8px로 줄이며 긴 내용은 줄바꿈합니다.
- 학력·경력 문자열을 임의로 분해하거나 새로운 사실을 추정하지 않고 원문과 줄바꿈을 유지합니다.
- 자기소개는 표 안에서 긴 문장을 행간 1.65로 표시합니다. 빈 정보 안내, 기존 연봉·추천인 포맷, 포트폴리오 링크와 첨부파일 다운로드 동작을 유지합니다.
- 다른 페이지의 기본 지원서 레이아웃은 유지합니다.


## 3개 주요 섹션의 외곽선

지원자 목록·지원서 상세·평가 패널의 최외곽 테두리는 제거하고 흰색 표면과 회색 페이지 배경으로만 구분합니다. Radius·배치·내부 패딩은 유지합니다. 내부 지원자 카드·평가자 카드·입력창·세그먼트·표·탭 구분선은 변경하지 않습니다.


## 활성 탭 외곽선

세 탭 그룹의 활성 버튼은 바깥 테두리와 테두리 역할의 inset 그림자 없이 옅은 선택 배경·글자 강조로만 구분합니다. 탭 그룹 하단의 옅은 1px 구분선과 키보드 포커스 표시는 유지합니다.


## 탭 여백 정렬

1차·2차 면접 탭과 우측 평가·히스토리·메모 탭은 좌우·상하 패딩을 모두 8px로 맞춥니다. 가운데 지원서·평가 탭의 기존 패딩은 유지합니다. 활성 탭 테두리는 없고 옅은 선택 배경과 하단 구분선은 유지합니다.


증명사진은 108×144px 크기·배경·모서리를 유지하고 외곽 테두리만 제거합니다. 면접전형의 summary 프로필에만 적용합니다.
`증명사진` 캡션은 사진 프레임 안쪽 하단 중앙에 10px로 배치합니다. 별도 배경색 없이 투명하게 표시해 사진 배경과 이어지게 하며 외부 캡션은 표시하지 않습니다.
기본 사진 대체 아이콘은 화면의 다른 아이콘과 같은 Lucide `UserRound` 라인 스타일을 사용합니다. 크기는 40px, 선 두께는 1.5px이며 프레임 중앙에 표시합니다. 실제 등록 사진은 기존 이미지 표시를 유지합니다.
기본 사진 상태에서는 아이콘 바로 아래 6px 간격으로 `증명사진` 텍스트를 배치하고, 아이콘·텍스트 묶음 전체를 사진 프레임의 가로·세로 중앙에 정렬합니다.

## 평가 세그먼트 외곽선과 배경

합격·불합격·보류 세그먼트의 트랙 외곽선과 활성 버튼의 테두리 역할을 하는 그림자를 제거합니다. 트랙 배경은 페이지와 같은 `--int-background` (`#F7F8FA`)를 사용합니다. 선택된 항목은 흰색 배경과 굵은 글자로 구분하며 내부 세로 구분선·선택 동작·키보드 포커스 표시는 유지합니다.

## 필터 드롭다운과 필수 표시

면접 목록의 계열사·공고·일정·면접 상태 필터는 커스텀 combobox/listbox를 사용합니다. 흰색 메뉴·6px 모서리·옅은 그림자와 중립색 hover/선택 배경, 선택 항목 체크 표시로 구성합니다. 메뉴 폭은 필터와 같으며 스크롤·화면 경계에 맞춰 위아래로 배치합니다. 방향키·Home/End·Enter/Space·Escape·Tab 및 바깥 클릭을 지원합니다. 기존 옵션·필터 값·계열사 권한·로딩 잠금은 유지합니다.

최종 코멘트의 필수 표시는 별표 대신 3px 빨간 점(`#C9372C`)으로 표시하고 보조기기에 `필수`로 안내합니다. 레이블은 flex 중앙 정렬과 4px 간격을 사용해 텍스트와 점의 세로 중심을 맞춥니다.

가운데 평가 탭의 서류 전형 평가자 카드도 `reviewer-summary-card`를 재사용합니다. 상단은 평가자 레이블·이름·제출 상태, 하단은 소속·평가 결정·수정 일시와 평가 코멘트 순서로 표시합니다. 기존 평가 열람 권한과 필드 표시 조건은 유지합니다.

## 우측 도구·평가 영역 구분

일정·AgentGO 도구 영역과 평가·히스토리·메모 영역은 같은 가로 폭의 흰색 표면으로 구성하고 사이에 12px의 페이지 배경 간격을 둡니다. 각 표면의 모서리는 8px이며 하단 영역은 탭 상단에도 곡률을 적용합니다. 외곽선은 추가하지 않고 기존 내부 카드·입력창·탭 구분선과 동작은 유지합니다.

면접전형의 기본 외곽선 토큰 `--int-border`·`--int-border-subtle`은 기본정보 테이블 구분선과 같은 `#EEF0F4`로 통일합니다. 선택된 지원자 카드의 강조선, hover·입력 포커스 색상은 유지합니다. 이미 제거한 외곽선은 다시 추가하지 않습니다.

최종 평가 제목과 최종 결정 레이블 사이의 간격은 16px로 표시합니다.
처우협의의 처우 제안 작성 영역에도 같은 위계를 적용합니다. 제목은 14px·600·#292C35, 하위 입력 레이블은 13px·400·#666D80이며 제목 아래 간격은 16px입니다.
최종 결정·최종 코멘트 레이블은 보조 텍스트 색상 `--int-text-secondary` (`#666D80`)과 400 두께를 사용해 상위 제목인 최종 평가(기본 텍스트 색상·600)와 구분합니다. 필수 표시의 빨간 점은 유지합니다.

### 대시보드 그래프

- 월별 지원자 현황: 기존 월별 인원 데이터를 그대로 사용하는 계단형 영역 그래프(`stepAfter`). 선 2px, 색상 `#7C8BA1`, 아래 영역은 같은 색의 옅은 그라데이션과 은은한 대각선 패턴. 가로 그리드만 `#EEF0F4`로 표시하고 축 선·눈금 선은 제거합니다. 툴팁은 해당 월과 실제 인원(명), 세로 점선과 작은 점으로 구성합니다.
- 전형 단계별 합격자 현황: 내부 반지름 75px·외부 반지름 81px의 얇은 링. 세그먼트 간격 6도, 끝은 둥글게 처리하고 중앙은 비웁니다. 하단에는 2열 범례로 색상 점·전형명·기존 계산 비율을 표시합니다. 마우스 오버 시 실제 인원을 표시합니다.
- 그래프 팔레트는 Atlassian의 라이트 차트 토큰 categorical.1~5인 `#357DE8`(Blue600), `#82B536`(Lime500), `#BF63F3`(Purple500), `#F68909`(Orange500), `#1558BC`(Blue800)을 사용합니다. 월별 그래프는 단일 브랜드 블루, 전형별 그래프는 순서대로 범주 색상을 적용합니다. 레퍼런스의 통화·증감률·누적 수치로 데이터를 바꾸지 않습니다.
- 빌드, 기존 상태/API/권한/변경 핸들러 유지 비교, 실제 툴팁 수치, 390px 모바일에서 그래프·범례의 가로 넘침 없음을 확인했습니다.

### 대시보드 세부 조정

- AgentGo 카드는 3열이며 내부 아이콘을 제거하고 카드명·사용 횟수를 유지합니다.
- 채용 진행 현황의 5개 카드 아이콘은 오른쪽 상단, 화살표는 같은 중심축의 바로 아래에 배치합니다.
- 전형별 범례는 2열, 열 간격 24px·행 간격 10px입니다. 전형명과 비율은 8px 간격으로 묶고 비율은 600 두께로 강조합니다. 비율을 셀 오른쪽 끝으로 밀어내지 않습니다.
- 대시보드 날짜 필터는 직접 입력이 가능한 커스텀 캘린더를 사용합니다. 흰색 280px 패널·8px 모서리·중립색 선택 배경, 연도/월 선택과 이전/다음 이동, 오늘/닫기 버튼으로 구성합니다. 월·연도 탐색은 조회를 바꾸지 않고 날짜 확정만 기존 필터 commit에 연결합니다. 방향키·Home/End·PageUp/Down·Escape, 바깥 클릭 닫기와 화면 경계 배치를 지원합니다. 유효한 YYYY-MM-DD 직접 입력은 Enter/포커스 이탈 때 반영하고 잘못된 날짜는 원래 값으로 되돌립니다.
- 채용공고 카드도 지원자 카드와 같은 상단 레이블·제목·상태, 중간 기간, 하단 레이블·값의 위계를 사용합니다. 총 지원자 숫자는 28px·700, 명 단위는 13px·500·보조색입니다.

### 채용공고·처우협의 목록 필터 위치

- 채용공고의 계열사·상태 필터, 처우협의의 계열사·공고·상태 필터는 면접전형과 같이 왼쪽 목록 섹션 상단에 한 열로 쌓습니다.
- 필터 영역은 8px 패딩·6px 간격이며 목록 폭을 채웁니다. 필터 아래의 카드 목록만 별도로 스크롤됩니다.
- 기존 필터 순서·권한별 노출·옵션·선택값·로딩/비활성 상태·변경 핸들러와 목록 스크롤 참조를 유지합니다.
